```cpp

if (boardSize == 11 && moveNum >= 11 && moveNum <= 49 && blackScythes > 0) {
    return true;

```

### 对比新旧代码
```cpp
// 旧代码（有问题）
if (canUseScythe()) {  // 每次都调用函数，慢
    // ...
}

// 新代码（优化后）

    // ...

    // ...
}
```

## 错误处理偏好

遇到错误时提供：
1. **错误是什么** - 简短描述
2. **为什么会出现** - 根本原因
3. **如何解决** - 具体步骤
4. **如何避免** - 预防措施

**示例：**
```
错误：找不到 ZLIB

原因：
ZLIB 库没有编译，或者路径不正确。
KataGo 需要 ZLIB 来压缩神经网络文件。

解决步骤：
1. 检查 D:\ScytheKatago\zlib\build\Release\ 目录
2. 如果没有 zs.lib 文件，运行 build.bat 重新编译
3. 如果有文件但还是报错，检查 CMakeLists.txt 中的路径

预防措施：
首次构建时使用 build.bat 而不是 compile.bat
```
