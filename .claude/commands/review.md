审查当前分支的所有代码改动：

1. 运行 `git diff` 查看所有未提交的改动
2. 检查代码质量：
   - 变量命名是否清晰
   - 逻辑是否正确
   - 是否有重复代码
3. 检查潜在问题：
   - 内存泄漏风险
   - 空指针解引用
   - 数组越界
   - 未初始化变量
4. 检查 C++ 最佳实践：
   - 是否使用了 C++17 特性（如 std::shuffle 而非 std::random_shuffle）
   - RAII 资源管理
5. 针对 KataGo/镰刀规则检查：
   - GTP 输出是否正确（调试信息必须发到 stderr）
   - 镰刀状态变量是否正确维护
6. 给出改进建议和风险评估
