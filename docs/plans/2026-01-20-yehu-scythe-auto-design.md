# 野狐镰刀自动对战系统设计

## 概述

**目标**：让镰刀 KataGo 在野狐平台上自动下 15 秒快棋

**用户**：小白用户，需要简单易用的工具

## 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                      野狐客户端                          │
│  (显示棋盘、镰刀提示"本回合走3步"、"黑方/白方镰刀")      │
└─────────────────────────────────────────────────────────┘
           ↑ 落子                    ↓ 截屏识别
┌──────────────────┐          ┌──────────────────────────┐
│    readboard     │←─棋盘───→│  镰刀检测工具 (新建)     │
│  (棋盘同步工具)   │  同步    │  检测"本回合走3步"       │
└──────────────────┘          └──────────────────────────┘
           ↑↓ GTP                      ↓ 模拟点击
┌─────────────────────────────────────────────────────────┐
│                    lizzieyzy                            │
│            (镰刀面板 ● 3 | ○ 3)                         │
└─────────────────────────────────────────────────────────┘
                          ↑↓ GTP
┌─────────────────────────────────────────────────────────┐
│                 KataGo (镰刀版 v1.2)                    │
│              计算最佳着法，镰刀时连续3步                 │
└─────────────────────────────────────────────────────────┘
```

## 新建：镰刀检测工具

### 功能
1. 监控野狐屏幕（每 200ms 检测一次）
2. 检测"本回合走3步"文字出现
3. 区分"黑方镰刀"或"白方镰刀"
4. 模拟点击 lizzieyzy 的镰刀按钮

### 检测方法：模板匹配
- 使用 OpenCV 模板匹配
- 速度快（<50ms），准确率高
- 需要用户提供模板截图

### 识别特征（从野狐截图提取）
- 顶部文字："本回合走3步"
- 中央文字："黑方镰刀" 或 "白方镰刀"
- 文字样式：蓝紫色渐变 + 白色描边

### 技术栈
- Python 3
- opencv-python (模板匹配)
- pyautogui (截屏 + 模拟点击)
- pillow (图像处理)

## 使用流程

1. 启动 lizzieyzy（连接 KataGo 镰刀版）
2. 启动 readboard（棋盘同步工具）
3. 启动镰刀检测工具
4. 打开野狐，进入镰刀对局
5. 工具自动检测镰刀并触发
