# v2.7 完整修复总结

## 修复内容

### Bug 1: 白方/黑方归属位置错误
**症状**: AI 移动棋子后显示为空，piece_color=Color.NONE

**原因**: piece_owners 初始化时白方和黑方位置搞反了

**修复**:
```python
# 正确的归属
for r in range(2):  # 黑方 (Row 0-1，棋谱第 8-7 排)
    piece_owners[(r, c)] = Color.BLACK

for r in range(6, 8):  # 白方 (Row 6-7，棋谱第 2-1 排)
    piece_owners[(r, c)] = Color.WHITE
```

### Bug 2: 棋子类型未初始化
**症状**: AI 移动 g1f3 后，g1 和 f3 都显示为空，piece_type=PieceType.EMPTY

**原因**: 只初始化了 piece_owners (归属)，但没有初始化 board (棋子类型)

**修复**: 完整重写 `_init_board` 方法，正确初始化标准国际象棋布局

## 完整的 _init_board 逻辑

### 三层状态模型

1. **Layer 1: board (棋子类型)**
   - Row 0: [R, N, B, Q, K, B, N, R] (黑方底线)
   - Row 1: [P, P, P, P, P, P, P, P] (黑方兵线)
   - Row 2-5: EMPTY
   - Row 6: [P, P, P, P, P, P, P, P] (白方兵线)
   - Row 7: [R, N, B, Q, K, B, N, R] (白方底线)

2. **Layer 2: piece_owners (棋子归属)**
   - Row 0-1: Color.BLACK (16 个黑方棋子)
   - Row 6-7: Color.WHITE (16 个白方棋子)

3. **Layer 3: revealed (翻开状态)**
   - 初始为空集合（暗棋模式）
   - 可选：全部翻开用于调试

## 坐标系统说明

**棋谱记号 → 数组坐标转换**:
```
row = 8 - 棋谱排号
col = ord(棋谱列号) - ord('a')

示例:
- e1 (白王) → row=7, col=4
- e8 (黑王) → row=0, col=4
- g1 (白马) → row=7, col=6
- g8 (黑马) → row=0, col=6
```
