# v2.7 Bug 修复总结

## Bug 描述
AI 移动 `d2d4` 后，目标格子显示为空，棋子消失。

## 根本原因
**白方和黑方的初始位置完全搞反了！**

### 坐标系统
- 棋谱记号转换：`row = 8 - 棋谱排号`
- 白方初始位置：棋谱第 1-2 排 → 数组 `row 6-7`
- 黑方初始位置：棋谱第 7-8 排 → 数组 `row 0-1`

### 错误代码
```python
# ❌ 错误版本
for r in range(2):  # 行 0-1
    self.piece_owners[(r, c)] = Color.WHITE  # 错误！应该是黑方

for r in range(6, 8):  # 行 6-7
    self.piece_owners[(r, c)] = Color.BLACK  # 错误！应该是白方
```

### 修复代码
```python
# ✅ 正确版本
for r in range(2):  # 黑方 (行 0-1，对应棋谱第 8-7 排)
    self.piece_owners[(r, c)] = Color.BLACK

for r in range(6, 8):  # 白方 (行 6-7，对应棋谱第 2-1 排)
    self.piece_owners[(r, c)] = Color.WHITE
```

## 修复影响
1. ✅ AI（白方）可以正确移动 d2, e2 等初始位置的棋子
2. ✅ 棋子颜色显示正确（白方显示白色，黑方显示黑色）
3. ✅ 移动后的格子会正确显示棋子图标或圆盘

2. 启动引擎，新对局
3. 勾选"AI 先手 (白)"
4. 观察 AI 是否能正确移动并显示棋子
