========================================
野狐镰刀自动对战系统 v1.0
========================================

【保护机制】
1. 模拟模式 - 只检测不点击，安全测试
2. 首次确认 - 第一次检测到需要人工确认
3. 冷却时间 - 3秒内不会重复触发
4. 详细日志 - 所有操作都有记录

========================================
使用步骤（按顺序）
========================================

【第1步：安装依赖】
双击 install.bat
(只需运行一次)

【第2步：运行自测】
双击 start_test.bat
检查所有测试是否通过

【第3步：准备模板】
1. 打开野狐，进入镰刀对局
2. 等"黑方镰刀"出现
3. 按 Win+Shift+S 截图，只截"黑方镰刀"四个字
4. 保存到 templates\black_scythe.png
5. 同样截"白方镰刀"，保存为 white_scythe.png

【第4步：模拟测试】
双击 start_dry_run.bat
打开野狐下镰刀棋，观察是否能检测到
(模拟模式不会实际点击)

【第5步：正式使用】
1. 启动 lizzieyzy (连接 KataGo 镰刀版)
2. 启动 readboard (棋盘同步)
3. 双击 start_scythe_auto.bat
4. 打开野狐，开始对局

========================================
文件说明
========================================

启动脚本：
  install.bat          - 安装依赖
  start_test.bat       - 运行自测
  start_dry_run.bat    - 模拟模式（安全测试）
  start_scythe_auto.bat - 正式启动

目录：
  templates/           - 模板图片
  logs/               - 日志文件
  test_images/        - 测试截图

========================================
命令行参数
========================================

python scythe_auto.py --test        # 运行自测
python scythe_auto.py --dry-run     # 模拟模式
python scythe_auto.py --no-confirm  # 跳过首次确认
python scythe_auto.py --interval 0.1 # 检测间隔(秒)
python scythe_auto.py --cooldown 2.0 # 冷却时间(秒)

========================================
常见问题
========================================

Q: 检测不到镰刀？
A: 1. 检查模板图片是否正确
   2. 尝试降低阈值 (修改代码中的 MATCH_THRESHOLD)
   3. 查看 logs 文件夹的截图

Q: 点击位置不对？
A: 需要调整代码中的按钮偏移量
   在 click_scythe_button 函数中修改 button_x 和 panel_y

Q: 触发太慢？
A: 用 --interval 0.1 参数减少检测间隔
