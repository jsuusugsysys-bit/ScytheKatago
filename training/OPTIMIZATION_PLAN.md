# 镰刀规则训练优化方案

## 核心洞察（用户提出）

**镰刀规则的关键特性**：
> 双方镰刀全部用完后，胜负往往一目了然，不需要下完整盘棋

这个洞察带来巨大的训练加速潜力！

## 优化策略矩阵

### 1. 对局长度优化（基于镰刀特性）

| 阶段 | 手数范围 | 作用 | 优化措施 |
|------|---------|------|---------|
| 开局 | 1-10 | 布局 | 正常 |
| **镰刀阶段** | 11-49 | **核心决战** | 高质量数据采集 |
| 镰刀后 | 50-65 | 形势判断 | **提前终止！** |
| 收官 | 65+ | 细棋 | **大多数对局不需要** |

**关键优化**：
```
原配置: maxMovesPerGame = 200  (浪费 135 手！)
优化后: maxMovesPerGame = 65   (节省 67% 计算量)
```

**数学估算**：
- 镰刀阶段：11-49手（39手）= 20% 的对局时间
- 产生 80% 的有价值训练数据（胜负关键在此）
- 镰刀后：如果大幅领先/落后 → 结果已定 → 无需继续

### 2. Resign 优化（加速形势明朗的对局）

```
原设置:
resignThreshold = -0.90     (几乎不认输)
resignConsecTurns = 3       (保守确认)

优化后:
resignThreshold = -0.85     (大幅落后就认输)
resignConsecTurns = 2       (镰刀后形势明朗)
resignMinMovesPerGame = 50  (至少让镰刀发挥完)
```

**预期效果**：
- 30-40% 对局在第 55-60 手结束（而非 80-200 手）
- 节省 30-50% 计算时间
- **不影响训练质量**（因为结果已经确定）

### 3. GPU 性能优化

| 参数 | 当前值 | 优化值 | 提升 |
|------|--------|--------|------|
| numGameThreads | 300 | **3200** | 10.6x |
| nnMaxBatchSize | 256 | **640** | 2.5x |
| maxVisits | 400 | **280** | 节省30% |
| cheapSearchProb | 0.70 | **0.85** | 更多快速搜索 |
| cheapSearchVisits | 80 | **50** | 11路够用 |

**预期GPU利用率**：15% → **75-90%**

### 4. 镰刀触发率策略

```
阶段1 (0-50万盘):   scytheRandomTriggerRate = 0.50  (让AI充分体验)
阶段2 (50-200万盘): scytheRandomTriggerRate = 0.35  (平衡训练)
阶段3 (200万+):     scytheRandomTriggerRate = 0.25  (接近实战)
```

## 训练策略建议

### 方案：纯镰刀规则训练（推荐）

**理由**（回答您的疑问）：
1. **镰刀规则可能不需要强大的19路棋力**
   - ✅ 11路本身就简单很多
   - ✅ 镰刀更强调战术性、爆发力
   - ✅ 与19路的大局观、厚薄不是一个维度

2. **从零开始可能更好**：
   - ✅ 避免19路的"固有套路"干扰镰刀思维
   - ✅ AI可能发现人类未知的镰刀战术
   - ✅ 训练速度更快（不需要大模型）

3. **人类棋谱 6万盘的使用**：
   ```
   阶段1 (0-100万盘): 纯自对弈
     → AI自由探索镰刀的各种可能性
     → 可能发现创新战术

   阶段2 (100万盘后): 可选择性引入人类棋谱
     → 学习人类的开局模式
     → 修正可能的"AI自嗨"
     → Fine-tune 提升实战表现
   ```

**建议**：先让AI自己玩，等它有了基础棋力（业余高段）再考虑人类棋谱。
